# 01 — Recursividad

## Temas a tocar

1. **Introducción a la recursividad**
   - Definición y conceptos fundamentales
   - Funciones recursivas clásicas: factorial, potencias, serie Fibonacci
   - La recursividad y la pila de llamadas

2. **Construcción de funciones recursivas**
   - Recursión con números
   - Recursión con listas
   - Recursión con matrices

3. **Vuelta atrás recursiva (Backtracking)**
   - Concepto y aplicaciones
   - Problema de las N reinas
   - Problema de la mochila (knapsack)

4. **Recursividad vs Iteración**
   - Comparación de enfoques
   - Trade-offs y casos de uso
