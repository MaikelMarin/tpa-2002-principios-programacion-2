# 04 — Grafos

## Temas a tocar

1. **Conceptos y características**
   - Definición de grafos
   - Tipos: dirigidos, no dirigidos, ponderados, bipartitos
   - Terminología fundamental

2. **Representación**
   - Lista de adyacencia
   - Matriz de adyacencia
   - Comparación de representaciones

3. **Operaciones básicas**
   - Añadir y eliminar nodos y aristas
   - Consultar vecinos

4. **Recorridos**
   - BFS (Breadth-First Search) con colas
   - DFS (Depth-First Search) con pilas

5. **Algoritmos clásicos**
   - Dijkstra (camino más corto)
   - Kruskal y Prim (MST)
   - Detección de ciclos
