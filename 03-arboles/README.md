# 03 — Árboles

## Temas a tocar

1. **Conceptos y características**
   - Definición de árboles
   - Tipos de árboles binarios
   - Terminología fundamental

2. **Implementación con listas**
   - Nodos y estructura
   - Operaciones básicas

3. **Árboles binarios**
   - Definición y características
   - Recorridos: inorden, preorden, postorden, por niveles

4. **Árboles de búsqueda binaria (BST)**
   - Definición y características
   - Operaciones: inserción, búsqueda, eliminación
   - Balanceo y variantes (AVL)
