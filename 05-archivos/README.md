# 05 — Procesamiento de Archivos

## Temas a tocar

1. **Sistemas de archivos**
   - Definición y evolución histórica
   - Tipos de archivos: texto y binario
   - Acceso secuencial y aleatorio

2. **Lectura y escritura de archivos de texto**
   - Modos de apertura
   - Operaciones básicas

3. **Archivos binarios**
   - Escritura y lectura binaria
   - Estructuras de datos binarias

4. **Acceso secuencial y aleatorio**
   - Seek y manipulación del puntero
   - Casos de uso
